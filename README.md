# Wizualizacja giętarki – jak uruchomić (bez instalowania czegokolwiek)

1. Załóż darmowe konto na github.com i kliknij **New repository** (nazwa dowolna, np. `giarka`).
2. Kliknij **uploading an existing file** i przeciągnij CAŁĄ zawartość tego folderu (razem z ukrytym folderem `.github`). Kliknij **Commit changes**.
3. Wejdź w **Settings → Pages → Source: GitHub Actions**.
4. Wejdź w zakładkę **Actions** i poczekaj ok. 1–2 min na zielony ptaszek.
5. Adres aplikacji pojawi się w Settings → Pages (https://TWOJNICK.github.io/giarka/).

## Instalacja jak aplikacja
- **iPhone:** Safari → Udostępnij → *Dodaj do ekranu początkowego*.
- **Android:** Chrome → menu ⋮ → *Zainstaluj aplikację*.
- **Windows:** Edge/Chrome → ikona instalacji w pasku adresu.
Każda zmiana plików w repozytorium = automatyczna nowa wersja.
